# Product Performance Dashboard | Power BI

## Project Overview

This project was completed as part of a Power BI internship exercise. The objective was to design an interactive Product Performance Dashboard that provides insights into sales performance, customer behavior, product contribution, and revenue trends.

## Dashboard Objectives

* Monitor key sales and customer metrics.
* Evaluate product performance based on revenue generated.
* Analyze customer purchasing behavior.
* Track revenue trends over time.
* Identify the most effective referral sources.
* Enable interactive analysis through slicers.

## Key Performance Indicators (KPIs)

* Total Orders
* Completed Orders
* Total Revenue
* Total Customers
* Average Order Value (AOV)
* Total Quantity Sold

## Dashboard Visuals

### Product Performance

Displays the total revenue generated by each product, helping identify top-performing products.

### Customer Analysis

Shows the distribution of Repeat Customers and One-Time Customers based on Customer ID.

### Monthly Sales Trend

Visualizes revenue performance across different months to identify sales patterns and trends.

### Revenue by Referral Source

Highlights the contribution of different referral channels to total revenue.

### Revenue Contribution Analysis

A table showing each product's percentage contribution to overall revenue.

## Interactive Features

The dashboard includes slicers for:

* Date
* Payment Method
* Order Status
* Referral Source

These filters allow users to interact with the dashboard and explore insights from different perspectives.

## Tools Used

* Power BI
* DAX
* Data Modeling
* Data Visualization
